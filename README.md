# Fraud Signal Detector

## Implementation status — 9 October 2026
This repository is documentation only (README). No runnable app, AI model, scoring endpoint or deployed fraud detection system is included. The features below are proposed, not implemented or certified. Use synthetic examples and qualified human review; a signal is not a fraud verdict. Do not upload confidential claims.

## Proposed workflow
Claims fraud signal scoring with explainable indicators and SIU referral support. Intended audience: insurers, MGAs, brokers and claims teams. A future implementation must document evidence, false positives, permissions and human approval.
